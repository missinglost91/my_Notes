**上传失败与解决方案**

环境文件、数据库太大了，github会终止上传

有密钥的一些文件，github会终止上传

设置`.gitignore`文件，来取消git对他们的版本跟踪

先删除缓存
```bash
git rm -r --cached .
```

```.gitignore
# 语法规则
# 忽略 node_modules 目录
node_modules/  
# 忽略所有 .log 文件
*.log
# 忽略 dist 目录
dist/
```
![20260208180231](https://lin01-image-1373317342.cos.ap-beijing.myqcloud.com/20260208180231.png)

这是忽略后的样子
