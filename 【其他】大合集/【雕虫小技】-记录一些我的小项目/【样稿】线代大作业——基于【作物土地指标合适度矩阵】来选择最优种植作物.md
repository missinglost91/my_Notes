# 线代期末大作业作业——基于【作物土地指标合适度矩阵】来选择最优种植作物（C语言实现）

关山难

## 研究目的

在农业生产中，不同农作物对土壤的 `土壤平均温度`，`土壤含水量`，`pH值`，`平均日光照`  
等多个因素有不同的要求。为了确定某块土地最适宜种植的农作物，
需要综合分析这些因素与各类农作物生长需求之间的匹配关系。
为此,我们提出了一个 **作物土地指标合适度矩阵** 的概念，我们可以将土地的各项环境因素和农作物的需求分别构建为向量和矩阵，利用线性代数中的运算知识以及函数拟合的知识，并利用C语言程序来实现，来选择这块土地上的最优种植作物，为农业生产提供更科学的指导。



## 研究过程


### 1. 实验假设与数据依据

假设我们有一块土地A，具有如下四个指标

`土壤平均温度`，`土壤含水量`，`pH值`，`平均日光照`

而我们此时要依据这块土地A的指标数据来决定种哪种作物

我提供了 `水稻`，`苹果`，`小麦` 这三种选择

>提供这三种作物原因:
> 
>此三种作物种植分布区差别较大，作3物习性的差别也较大，便于我们的后续评估

从网上考察相关资料，得出三种作物分别 的【最适温度区间】，【最适土壤水分区间】，【最适pH范围】，【最适日光照区间】的相关数值

构造的 3*4 的 **区间矩阵**

| 植物名称 | 最适温度区间     | 最适土壤水分区间     | 最适pH范围     | 最适日光照区间   |     
| ---- | -------- | -------- | --------- |-----------|
| 小麦   | 16 - 20℃ | 60 - 70% | 6.0 - 7.0 | 8 - 12小时  |     
| 苹果   | 10 - 15℃ | 60 - 80% | 6.5 - 7.0 | 10 - 12小时 |     
| 水稻   | 20 - 30℃ | 80 - 90% | 5.5 - 7.5 | 8 - 10小时  |     


我们采用一个含有两个元素的结构体来存放构造 3*4 的**区间矩阵**

>该部分的程序实现：

```C

struct qujian
	{
		float a;
		float b;
	};
	typedef struct qujian  st_qujian;

st_qujian qujian_matrix[3][4] =//构造区间（a,b）的 3*4 矩阵
	{
	{{16,20},{60,70},{6.0,7.0},{8,12}  },//小麦的【最适温度区间】，【最适土壤水分区间】，【最适pH范围】，【最适日光照区间】
	{{10,15},{60,80},{6.5,7.0},{10,12} },//苹果的【最适温度区间】，【最适土壤水分区间】，【最适pH范围】，【最适日光照区间】
	{{20,30},{80,90},{5.5,7.5},{8,10}  }//水稻的【最适温度区间】，【最适土壤水分区间】，【最适pH范围】，【最适日光照区间】
	};
```


### 2. 拟合函数

#### 2.1 提出模型的要求
那么我们可以依据各个指标的区间的数值来构造 **不同植物对于不同指标的生长合适度函数曲线**

函数的横坐标为该项**指标的数值**，纵坐标为该植物在该指标下的**生长合适度**

>生长合适度：
> 
> 某一作物在某一指标下，该指标的数据与该植物生长所需要的区间的匹配程度
>
>（最高为1，最差为0）

#### 2.2 找到符合模型

我们最后选择用一个伪正态分布曲线来拟合

$$
y=e^{\frac{\left (x-c    \right)^{2}  }{2 d^{2} } }
$$

>用伪正态分布曲线来拟合的原因:
> 
>该函数满足最高值为1，最低值趋近于0的【生长合适度】条件
>
> c代表对称轴,d代表标准差


#### 2.3 计算模型的参数

那么三种作物，对于四个指标都有自己的 **生长合适度伪正态曲线**

如何填入这不同的12个曲线中，每个曲线的 **c（对称轴）** 与 **d（标准差）** 这两个参数呢

我这里采用了一种比较巧妙的策略

首先，对称轴就是区间矩阵的每个元素中的区间边界取中间值，十分简单

然后，我们不妨用采用区间矩阵的一个边界(我这里采用左边界，其实采用左右边界效果一样)，
将最适区间左边界数值对应的生长合适度统一为 0.6，那么我们就拥有了一个样本点，即

**（区间的左边界，区间的左边界对应的合适度）**

将其带入伪正态曲线中，就能实现我们所需的 **d(标准差)**

>该部分的程序实现：


```C

#define interval_margin_value 0.6 //区间的边界对应的合适度

struct zhengtai_fun
	{
		float c;//正态曲线的对称轴
		float d;//正态曲线的标准差
	};
	typedef struct zhengtai_fun st_zhengtai;

	st_zhengtai zhengtai_matrix[3][4];// 构造正态曲线（对称轴，标准差）的 3*4 矩阵


	for (int i = 0; i < 3; i++)
	{
		for (int j = 0; j < 4; j++)
		{
			//拟合不同植物对于不同指标的生长合适度正态曲线
			zhengtai_matrix[i][j].c = (qujian_matrix[i][j].a + qujian_matrix[i][j].b) / 2.0; //用区间边界计算正态曲线的对称轴
			zhengtai_matrix[i][j].d = pow((-1.0)* pow(qujian_matrix[i][j].a - zhengtai_matrix[i][j].c, 2) / (2 * log(interval_margin_value)), 0.5);//利用（区间的左边界，区间的左边界对应的合适度）这一样本点，计算出正态曲线的标准差
		}

	}
```

### 3. 求出合适度矩阵

让用户输入土地A的各项指标，
`土壤平均温度`，`土壤含水量`，`pH值`，`平均日光照`、


我们假设用户输入了以下数据

存入土壤指标矩阵

|     | 土壤平均温度（摄氏度） | 土壤含水量（%） | pH值 | 平均日光照（小时） |
| --- | ----------- | -------- | --- | --------- |
| 土地A | 23          | 78       | 6.2 | 9.2       |



我们将土壤的各项指标依次带入 `水稻`，`苹果`，`小麦` 对应的各项指标的生长合适度伪正态曲线

得到 **合适度矩阵**

| 植物名称 | 最适温度区间   | 最适土壤水分区间 | 最适pH范围   | 最适日光照区间  |
| ---- | -------- | -------- | -------- | -------- |
| 小麦   | 0.041464 | 0.031980 | 0.832488 | 0.921749 |
| 苹果   | 0.000125 | 0.721855 | 0.085021 | 0.192045 |
| 水稻   | 0.921749 | 0.368556 | 0.955200 | 0.979835 |

将合适度矩阵乘上一个**权重向量**

|               | 土壤平均温度（摄氏度） | 土壤含水量（%） | pH值 | 平均日光照（小时） |
| ------------- | ----------- | -------- | --- | --------- |
| 评价作物总合适度所占的权重 | 30%         | 20%      | 20% | 30%       |

$$
\begin{pmatrix}
   0.041464 & 0.031980 & 0.832488 & 0.921749 \\
   0.000125&  0.721855 &  0.085021 & 0.192045 \\
 0.921749 &  0.368556 &   0.955200 &  0.979835
\end{pmatrix}*\begin{pmatrix}
 0.3\\
 0.2\\
 0.2\\
0.3
\end{pmatrix}
$$

得到**总合适度矩阵**

$$
=\begin{pmatrix}
 0.372881\\
0.272007 \\
0.774099
\end{pmatrix}
$$

|        | 小麦       | 苹果       | 水稻       | 
|--------|----------|----------|----------|
| 总合适度 | 0.372881 | 0.272007 | 0.774099 |     


由于水稻的总合适度最大，故我们在土地A上**种植水稻为最佳选择**


>该部分的程序实现：

```C

	float land[4] = { 0 }; //定义土壤的指标 1*4 矩阵（温度 ，土壤水分，土壤pH，光照）
	printf("请输入该土地的常年温度(摄氏度)   土壤水分(%)  土壤pH值   日光照时长(h)\n");
	scanf("%f%f%f%f", &land[0], &land[1], &land[2], &land[3]); //输入土壤的指标矩阵

	float value_matrix[3][4];//初始化合适度矩阵 

	for (int i = 0; i < 3; i++)
	{
		for (int j = 0; j < 4; j++)
		{
			value_matrix[i][j] = pow(2.71, 0.5*(-1)*pow((land[j] - zhengtai_matrix[i][j].c), 2) / pow(zhengtai_matrix[i][j].d, 2)); //将土壤的每个指标代入各植物的生长合适度正态曲线，得到各植物在该土壤的各指标下的3*4合适度矩阵
		}

	}

	printf("合适度矩阵如下\n");
	for (int i = 0; i < 3; i++)
	{
		for (int j = 0; j < 4; j++)
		{
			printf("%f   ", value_matrix[i][j]);
		}
		printf("\n");
	}
	printf("\n");




	float evaluation_weight_matrix[4] = { 0.3,0.3,0.2,0.2 };  // 4*1 指标权重矩阵

	float score[3];

	for (int x = 0; x < 3; x++)
	{
		score[x] = evaluation_weight_matrix[0] * value_matrix[x][0] + evaluation_weight_matrix[1] * value_matrix[x][1] + evaluation_weight_matrix[2] * value_matrix[x][2] + evaluation_weight_matrix[3] * value_matrix[x][3];
	}  //将合适度 3*4 矩阵 乘上 4*1 指标权重矩阵 得到 总合适度矩阵

	printf("种植小麦的总合适度为 %f\n", score[0]);
	printf("种植苹果的总合适度为 %f\n", score[1]);
	printf("种植水稻的总合适度为 %f\n", score[2]);
	
	printf("\n");

	//比较得出结论
	printf("经过分析，结论是：");
	if (score[0] > score[1] && score[0] > score[2])
		printf("这块土地最好拿来种小麦\n");
	else if (score[1] > score[0] && score[1] > score[2])
		printf("这块土地最好拿来种苹果\n");
	else
		printf("这块土地最好拿来种水稻\n");


```

## 仍存在的不足

### 1.评价作物合适度的指标不够多

作物在生长时，不止受到`土壤平均温度`，`土壤含水量`，`pH值`，`平均日光照` 的影响，还有许多其他因素的影响
比如`施肥量`，`无机盐量`，`土壤肥力`等影响，我在实验时为方便计算只考虑了四个比较重要的指标


### 2.权重向量不够符合实际情况

权重是由我自己规定的过于主观，但实际上并非如此，
各指标的权重可以用层次分析法或者Topsis法来更加优化

### 3.拟合的合适度函数不够符合实际情况

合适度函数不一定是伪正态分布曲线，我为了方便计算而过于理想化拟合出函数。
