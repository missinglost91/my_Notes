## ⚠️ 使用说明

- **学习内容**：本仓库笔记以学习记录为目的，代码可能未经充分生产环境测试，不建议直接用于生产环境
- **笔记格式**：以 `.md` Markdown 和 `.ipynb` Jupyter Notebook 为主，部分内容含代码片段与运行结果
- **大文件排除**：模型权重（`.safetensors`）、数据集（`.npy`/`.npz`/`.csv`）、镜像文件（`.img`）等大型文件未入库，仅保留笔记文本
- **私有内容**：涉及个人隐私与未公开项目的目录（`【私密】`、`【我的项目】`）已排除，不在仓库中
